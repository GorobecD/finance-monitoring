# NEON//FIN

Desktop-застосунок для особистого фінансового моніторингу (Tauri 2 + React). Кіберпанк-інтерфейс, усі дані локально.

## Можливості
- **ЗП щомісяця** — кнопка `+ ЗП` → автоматичний розподіл за правилом 50/30/20 (налаштовується) + переказ у подушку одним кліком
- **Доходи**: зарплата, премії, фріланс, пасивний дохід; UAH / USD / EUR з курсом НБУ (авто) або вручну
- **Витрати за категоріями** (потреби / бажання), редагування категорій
- **Бюджети** — місячні ліміти з підказкою середніх витрат, попередження при 80% і перевищенні
- **Фінансова подушка** — ціль = N місяців середніх витрат (за замовч. 6)
- **Цілі заощаджень** — сума, дедлайн, скільки відкладати на місяць
- **Інвестиції** — депозити / ОВДП (нараховані %), акції / ETF (P&L), валюта готівкою
- **Борги** — кому позичив / кому винен, часткові повернення, дедлайни
- **Регулярні платежі** — оренда, підписки, комуналка; проведення одним кліком
- **Огляд** — чистий капітал, динаміка 12 міс, структура витрат і капіталу, системні сповіщення
- Експорт / імпорт JSON-бекапу

## Дані
`%APPDATA%\ua.neonfin.app\neonfin-data.json` (+ автоматична копія `neonfin-data.backup.json`). Запис атомарний.

## Збірка
**GitHub Actions**: пуш у `main` → вкладка *Actions* → останній запуск → артефакт `NEON-FIN-windows-setup` (`.exe`-інсталятор).
Тег `v1.0.0` → інсталятор додається до GitHub Release.

**Локально (Windows)**: потрібні [Rust](https://rustup.rs) і Node 22.
```
npm install
npm run tauri dev     # розробка
npm run tauri build   # інсталятор у src-tauri/target/release/bundle/nsis/
```

Гарячі клавіші: `Ctrl+N` — нова витрата, `Esc` — закрити вікно, подвійний клік по рядку — редагувати.
